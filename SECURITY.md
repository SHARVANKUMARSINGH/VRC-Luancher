# Security Policy

## Supported Versions

We provide security and stability fixes for the latest release branch of Vrc Luancher.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The safety of player accounts (including Microsoft OAuth tokens and local session credentials) is taken very seriously.

If you discover a security vulnerability, credential leak risk, or sandbox escape:
1. **Do not create a public issue**.
2. Privately report the issue via GitHub's [Security Advisory Portal](https://github.com/VivxKumar07/Cubiq-Launcher/security/advisories/new) or contact the lead maintainer directly via GitHub ([@VivxKumar07](https://github.com/VivxKumar07)).
3. Please include detailed proof of concept, impact analysis, and reproduction steps.

We will acknowledge receipt within 48 hours and coordinate a timely fix and disclosure notice.
